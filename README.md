# 인생샷 카메라

좋아하는 사진을 넣어 두면, 새로 찍을 때 그 사진과 같은 구도·색감이 나오도록
찍는 사람을 안내하고 자리가 맞는 순간 자동으로 찍어 주는 폰용 웹 카메라.

## 폰에서 실행

1. `폰으로 실행.command`를 더블클릭한다. (또는 `python3 serve.py`)
2. 폰을 이 Mac과 같은 와이파이에 연결하고, 창에 표시된 `https://…:8443` 주소를 연다.
3. 처음 한 번 나오는 인증서 경고는 "세부사항 보기 → 이 웹 사이트 방문"으로 넘어간다.
4. 공유 → **홈 화면에 추가**를 하면 앱처럼 쓸 수 있다.

Mac이 켜져 있고 서버 창이 열려 있는 동안만 접속된다.

## 동작 방식

- **취향 분석**: 넣은 사진마다 인물 자세(MediaPipe Pose), 화면 비율, 색 분포(Lab)를 분석한다.
  가장 많이 좋아한 구도(전신 / 무릎 위 / 상반신 / 가슴 위 / 얼굴)를 "내 취향"으로 삼는다.
- **촬영 위치 안내**: 지금 화면 속 인물의 크기·위치를 좋아하는 사진과 비교해
  "더 가까이", "뒤로", "왼쪽으로"를 알려 준다. 거리 막대의 초록 구간이 맞는 거리다.
- **자동 촬영**: 거리·위치·수평이 맞은 채 0.9초 유지되면 찍는다. 남은 미세한 차이는 자동으로 잘라 맞춘다.
- **색감 맞춤**: 찍는 순간 좋아하는 사진의 밝기·색 분포로 옮겨 저장한다.
- **학습**: 찍은 사진에서 "♥ 취향에 추가"를 누르면 다음 촬영 기준에 포함된다.

사진과 분석 결과는 폰 브라우저 안(IndexedDB)에만 저장되고 밖으로 전송되지 않는다.

## 알아둘 점

- 브라우저 카메라는 동영상 프레임을 쓰므로 기본 카메라 앱보다 해상도가 낮다(기기에 따라 최대 4K 프레임).
- 사진 앨범에 넣으려면 찍은 사진 화면에서 **저장**을 눌러 공유 창의 "이미지 저장"을 고른다.
- 인물은 한 명 기준이다. 풍경·사물 사진은 겹쳐 보기와 닮음 정도만 안내하고 직접 누른다.
- 개발 확인용: `python3 serve.py --http 5178` 후 `http://localhost:5178/?src=이미지경로` 로 카메라 대신 파일을 입력으로 쓸 수 있다.
